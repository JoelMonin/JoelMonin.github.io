# Casa Somba — copie de travail

Ce dépôt ne contient **pas de code source** : il contient la **sortie** d'un site en
préparation, déposée telle quelle pour être regardée sur un téléphone ou un ordinateur.

- Ce n'est **pas** le site public de Casa Somba.
- Il n'est **pas destiné à être référencé** : chaque page porte `noindex, nofollow`,
  `robots.txt` interdit l'exploration, et aucun plan de site n'est publié.
- Le formulaire de contact **n'envoie rien** — la page le dit à l'écran.
- Le contenu peut être faux, incomplet ou changer sans préavis.

Les sources, elles, vivent dans un dépôt privé.
